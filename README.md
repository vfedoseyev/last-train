# Последний поезд

> Не было злодея. Не было убийцы.

Браузерная point-and-click игра о школьнике Артёме и тайне старого северного посёлка. Пролог и Глава 1 из полной истории (GDD) — первое знакомство с игрой.

**Играть:** https://vfedoseyev.github.io/last-train/

## Разработка

```bash
npm install
npm run dev
```

- `npm run build` — продакшен-сборка (`dist/`)
- `npm run lint` — oxlint
